# Personal Task Manager PWA

A clean, responsive, offline-first Personal Task Manager built with React and Recharts, deployable as a Progressive Web App (PWA).

## Features

- **Nested Subtasks:** Create hierarchical task structures with deep nesting support.
- **Custom Checklists & Tags:** Add custom action items (e.g., Notes, Revision, Exam) to individual tasks.
- **Due Dates & Tracking:** Set due dates with visual badges for upcoming and overdue tasks.
- **Activity & Analytics:** Visual completion progress ring and activity bar chart powered by Recharts.
- **Local Persistence:** Data automatically saves to browser local storage.
- **PWA Support:** Installable on desktop and mobile devices.

## Tech Stack

- **Framework:** React 18
- **Icons:** Lucide React
- **Charts:** Recharts
- **Deployment:** GitHub Pages via GitHub Actions
